# AI利用記録

- 対象: `ch02/ex04/index.js`（Unicodeエスケープシーケンスによる"Hello,world!"の出力）
- 日付: 2026-09-02
- ツール: Claude Code

## 使い方

問題2.4について、解答コードの作成は依頼せず、調べ方の相談・概念の説明・動作確認の目的でAIを利用した。実装はすべて自分で行った。

やり取りの経過は以下のとおり。

1. `He...`のようなUnicodeエスケープシーケンスを、外部の変換サイトを経由せず自力で調べる方法があるか質問した。回答として、JavaScriptの`codePointAt()`と`toString(16)`を組み合わせる方法、ASCII表の規則性から計算する方法、エディタのUnicode表示機能、PowerShellでの調べ方の候補を得た。
2. 提示された方法のうち`"H".codePointAt(0).toString(16)`をNode REPLで実際に試した上で、この式の意味（`codePointAt(0)`が文字のコードポイントを10進数で返すこと、`toString(16)`がその数値を16進数の文字列に変換すること）の説明を受けた。
3. `[...."Hello,world!"].map(c => c.codePointAt(0).toString(16).padStart(4, "0"))`をNode REPLで実行した結果と、`index.js`に書いていたエスケープシーケンス版の文字列を見比べ、結果が異なっていないことを確認した。これに対しAIが自身の実行環境で同じコードを実行して照合し、一致していることを確認した。

## 自分で書いた部分

- `index.js`の解答本体（`const hi = "H...!";`とその出力）
- Node REPLでの動作確認コード（`codePointAt`/`toString(16)`の実行、`map`による一括変換）

## AIが直接書いたコード

なし。差異の有無を確認するため、AIが同等の検証コードを自身の実行環境で実行して結果を照合したのみで、`index.js`本体への追加・変更は行っていない。
